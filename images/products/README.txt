Put your product photos in this folder.

In the admin dashboard's image field for a product you can then type just the file name,
for example:  cover-red.jpg
The site reads that as images/products/cover-red.jpg.

A full web address (https://...) or a path with a slash in it is used exactly as typed.
The folder this shortcut points at is catalog.imageFolder in js/config.js.
